# Kinesia for Developers

Documentación de [KinesiaMotion](https://github.com/elmaedesistemas/kinesia-motion), hecha con [Starlight](https://starlight.astro.build) (Astro).

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # sitio estático en dist/
```

- Las páginas están en `src/content/docs/` (Markdown / MDX). El menú lateral se define en `astro.config.mjs`.
- Los colores y la tipografía de marca están en `src/styles/kinesia.css`.
- Al publicar una versión nueva del SDK, actualiza `referencia/versiones.md` y la versión en `empezar/instalacion.md`.
