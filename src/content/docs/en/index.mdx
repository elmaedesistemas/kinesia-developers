## What it looks like in code

```swift
import KinesiaMotion
import KinesiaMotionVision

let session = MotionSession(exercise: ExerciseLibrary.elbowFlexion, side: .right)
session.start(with: VisionPoseProvider(camera: .front))

for await event in session.events() {
    if case .repCompleted(let rep) = event {
        print("Clean rep: \(Int(rep.peak))°")
    }
}
```

## What it solves

<CardGrid>
	<Card title="Measurements in degrees" icon="seti:pipeline">
		Flexion, angle from vertical and tilt, computed on the 19 body points that Vision detects.
	</Card>
	<Card title="Reps and holds" icon="approve-check">
		Counts reps with hysteresis (no false positives from jitter) and times held positions with a clock that
		restarts if the patient moves.
	</Card>
	<Card title="Live form checks" icon="warning">
		Each exercise comes with form rules ("keep your upper arm still", "keep your trunk upright"). Reps done
		with poor form are rejected, not counted.
	</Card>
	<Card title="Exercises as data" icon="document">
		An exercise is plain JSON: add a new one, or download it from your server, without touching the engine.
	</Card>
</CardGrid>
