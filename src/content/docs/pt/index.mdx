## Assim fica no código

<Tabs syncKey="platform">
<TabItem label="iOS · Swift">

```swift
import KinesiaMotion
import KinesiaMotionVision

let session = MotionSession(exercise: ExerciseLibrary.elbowFlexion, side: .right)
session.start(with: VisionPoseProvider(camera: .front))

for await event in session.events() {
    if case .repCompleted(let rep) = event {
        print("Repetição limpa: \(Int(rep.peak))°")
    }
}
```

</TabItem>
<TabItem label="Android · Kotlin">

```kotlin
import one.kinesia.motion.*
import one.kinesia.motion.camera.CameraPoseProvider

val session = MotionSession(ExerciseLibrary.elbowFlexion, BodySide.RIGHT)
session.start(CameraPoseProvider(context, lifecycleOwner), lifecycleScope)

session.events.collect { event ->
    if (event is MotionEvent.RepCompleted) {
        println("Repetição limpa: ${event.rep.peak.roundToInt()}°")
    }
}
```

</TabItem>

## O que resolve

<CardGrid>
	<Card title="Medições em graus" icon="seti:pipeline">
		Flexão, ângulo em relação à vertical e inclinação, calculados sobre 19 pontos do corpo, com o Apple Vision no iOS e o MediaPipe no Android.
	</Card>
	<Card title="Repetições e sustentações" icon="approve-check">
		Conta repetições com histerese (sem falsos positivos por tremor) e mede posições sustentadas com um relógio
		que reinicia se o paciente se mexer.
	</Card>
	<Card title="Técnica ao vivo" icon="warning">
		Cada exercício traz regras de forma («mantenha o braço junto ao corpo», «tronco reto»). Repetições com técnica
		ruim são rejeitadas, não contadas.
	</Card>
	<Card title="Exercícios como dados" icon="document">
		Um exercício é JSON puro, o mesmo no iOS e no Android: adicione um novo, ou baixe do seu servidor, sem tocar no motor.
	</Card>
</CardGrid>
