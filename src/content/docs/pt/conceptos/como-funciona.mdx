## 1. A fonte de poses

Um [`PoseProvider`](/pt/referencia/api/pose-provider/) entrega um `AsyncStream<Pose>`. Pode ser a câmera ([`VisionPoseProvider`](/pt/guias/camara-vision/)), uma gravação ([`RecordedPoseProvider`](/pt/guias/pruebas-y-grabaciones/)) ou o que você implementar. Cada [`Pose`](/pt/conceptos/pose/) são os pontos do corpo de um quadro, em pixels e com os lados já corrigidos.

## 2. A sessão

[`MotionSession`](/pt/referencia/api/motion-session/) é a porta de entrada. Para cada pose:

1. **Visibilidade.** Todas as articulações que o exercício mede estão visíveis? A mudança é confirmada após alguns quadros seguidos (~0,25 s) para não piscar.
2. **Posicionamento.** [`SetupCheck`](/pt/guias/calidad-de-medicion/) verifica se o paciente está de frente ou de lado, longe demais ou na borda da imagem.
3. **Motor.** [`RepEngine`](/pt/conceptos/repeticiones/) calcula a medição principal, suaviza, verifica as regras de forma e decide se uma repetição terminou.
4. **Medição inicial.** Se houver uma em andamento, atualiza o progresso.

Depois publica o resultado de duas formas.

## 3. Snapshot e eventos

| | `MotionSnapshot` | `MotionEvent` |
| --- | --- | --- |
| O que é | O estado completo, em um valor | Algo que aconteceu neste quadro |
| Como ler | `session.snapshot` (observável) | `for await event in session.events()` |
| Para quê | Desenhar: ângulo, contador, anel de progresso | Reagir uma vez: dizer «muito bem!», vibrar, salvar |

Mais detalhes em [Eventos e snapshot](/pt/guias/eventos-y-snapshot/).

## Os exercícios são dados

O motor não tem nenhum exercício programado. Um [`ExerciseDefinition`](/pt/referencia/api/exercise-definition/) descreve:

- **o que medir** (`primary`, uma [`Measure`](/pt/referencia/api/measure/)),
- **como contar** (`kind`: repetições ou sustentação),
- **que técnica exigir** (`rules`, uma lista de [`FormRule`](/pt/referencia/api/exercise-definition/#formrule)),
- **de onde olhar** (`view`: de lado ou de frente).

Como tudo é `Codable`, um exercício novo pode chegar em JSON do seu servidor. Veja [Exercícios personalizados](/pt/guias/ejercicios-personalizados/).
